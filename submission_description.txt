This report presents an end-to-end unsupervised learning project using the public Iris flower measurements dataset. The objective was to discover meaningful groups in numeric data without using known species labels during model fitting. The dataset contains 150 samples and four measurements: sepal length, sepal width, petal length, and petal width. The sample identifier was excluded from the feature matrix, and StandardScaler was used so that the distance-based K-Means algorithm would not be dominated by differences in feature spread.

K-Means was fitted for candidate cluster counts from 2 through 6, with a fixed random seed and multiple initializations for reproducibility. The number of clusters was selected using the silhouette score, and the analysis also reports the Davies–Bouldin index and Calinski–Harabasz score. The report includes a candidate-k metric table, a silhouette comparison plot, a PCA projection of cluster assignments, a chart of mean feature measurements by cluster, and a Ward hierarchical-clustering dendrogram. The cluster profiles are presented in the original measurement units to make the results easier to interpret.

The discussion explains the meaning and limitations of each metric, the rationale for standardization, and the difference between K-Means and hierarchical clustering. It also describes how similar workflows can support customer, product, or research segmentation while emphasizing that clusters require domain validation before practical use. The project folder contains the Word report, a README with setup instructions, requirements.txt, reusable Python source code, the input dataset, the cluster assignment output, model-selection metrics, and generated figures. The script can be rerun to reproduce the analysis and outputs. The analysis is exploratory: cluster numbers are arbitrary, PCA is only a two-dimensional visualization, and the best k is the highest-scoring option among the tested values rather than a universal truth.
